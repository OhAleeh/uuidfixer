# UUID Fixer v2.0.0 - 26.3

**Requires:** Minecraft Java 26.3 · Fabric Loader ≥ 0.19.0 · Fabric API

## What's new
- Added support for Minecraft 26.3.

## Installation
Drop `uuidfixer-2.0.0 - 26.3.jar` into your server's `mods` folder, replacing any previous version. Your existing `config/uuidfixer/cache.json` is kept and compatible.
